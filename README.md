Food Waste Donation Portal is a web application that replaces phone-call and paper-based food donation coordination with an online workflow. Donors submit surplus food, NGOs raise requests, admins approve them, and staff handle collection, with status tracking at every step.

Features

3 role-based modules: Admin, Donor, Staff
Secure login and session handling
Donation submission with form validation
NGO food requests and admin approval
Feedback and profile management
MySQL database with 3 tables

Tech stack: PHP, MySQL, HTML, CSS, JavaScript, Bootstrap

Testing: 10 test cases across 8 modules, all passing
